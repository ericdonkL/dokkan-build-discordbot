1. Information We Collect
The Bot operates with minimal data storage. The only information stored on the host server consists of:

Saved Build Inputs: Custom build details (e.g., unit configurations, hidden potential choices, or notes) entered by users.

Discord Display Name: The public display name of the user who submitted the build, saved solely to give credit within that server.

Storage Details: Data is saved directly on the hosting server in server-specific JSON files (.json). The Bot does not collect, track, or store Discord User IDs, email addresses, IP addresses, private messages, or any personal credentials.

2. How We Use Your Data
Stored build data and display names are used exclusively to:

Save and display custom builds within the server where they were created.

Credit the creator's display name alongside their submitted build.

Because Discord User IDs are not stored, build entries are tied only to the text string of the display name provided at the time of submission.

3. Data Retention & Third-Party Sharing
All data remains in local .json files on the bot host server.

We do not sell, rent, or share stored build logs or display names with any third parties.

4. Data Deletion & Modification Requests
Server administrators or build submitters who wish to have specific build inputs or display names modified or deleted from a server's JSON file can:

Delete the build entry directly using in-bot commands (if supported by your server setup).

Open an issue or request on the official repository:
